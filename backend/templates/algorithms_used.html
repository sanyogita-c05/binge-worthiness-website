🧠 Algorithms Used in Our Project

📌 Linear Regression

Main machine learning algorithm used to predict binge score based on multiple input features such as rating, popularity, votes, recency, time score and engagement.

⭐ Weighted Scoring Logic

Used in personalized recommendations by combining base binge score, genre match, mood match and available time with custom weights.

📈 Ranking Algorithm

Sorts movies and web series from highest to lowest binge score or predicted score to show the best recommendations first.

🔍 Filtering Logic

Filters results based on user constraints such as time available, mood, selected genres, content type and top-N selection.

🧪 Feature Engineering

Created smart features like total watch time, time score, engagement score, normalized rating, normalized popularity and recency score.

📊 Model Evaluation

Measured model performance using real dataset metrics: MAE, RMSE and R² Score after train-test split evaluation.

These algorithms work together to make the Binge-Worthiness platform predictive, personalized and data-driven.
