🧠 Algorithms Used in Our Project

⭐ Weighted Scoring

Combines rating, popularity, completion rate and rewatch value using custom weights to generate binge score.

📈 Ranking Algorithm

Sorts all movies and shows from highest to lowest predicted binge score.

🤖 Machine Learning Prediction

Uses trained ML model from model.py to predict binge-worthiness for unseen titles.

🔍 Filtering Logic

Filters recommendations based on time available, mood, type and user preferences.

📊 Feature Engineering

Created features like normalized rating, recency, runtime, total watch time and trend score.

📉 Error Evaluation

Measured prediction quality using MAE, RMSE, Accuracy and R² Score.
